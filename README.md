# LiveHavana.com landing page

Premium single-page landing website for the `livehavana.com` domain sale.

## Stack

- Next.js 15 App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Vercel-ready deployment

## Project structure

```txt
app/
  globals.css
  layout.tsx
  page.tsx
components/
  domain-landing.tsx
```

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run start
```

The site intentionally communicates that LiveHavana.com is only a domain for sale and not an operating business.
